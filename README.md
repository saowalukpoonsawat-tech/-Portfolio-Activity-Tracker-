# ระบบบันทึกผลงานส่วนบุคคล (Portfolio & Activity Tracker)

เว็บแอปสำหรับบันทึกและจัดการผลงาน กิจกรรม การอบรม และรางวัลของคุณ
พร้อมแดชบอร์ดสรุปสถิติ และหน้าพอร์ตโฟลิโอสาธารณะที่แชร์ได้

- **Single file** — โค้ดทั้งหมดอยู่ใน [`app.py`](app.py) ไฟล์เดียว
- **Flask + SQLite** — ฐานข้อมูล `portfolio.db` สร้างอัตโนมัติเมื่อรันครั้งแรก
- **Tailwind CSS (CDN)** — ไม่ต้อง build ไม่ต้องติดตั้ง Node

---

## ความต้องการของระบบ

- Python 3.9 ขึ้นไป
- การเชื่อมต่ออินเทอร์เน็ต (โหลด Tailwind และฟอนต์จาก CDN)

---

## การติดตั้งและรัน

```bash
pip install flask
```

```bash
python app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ **http://127.0.0.1:5000**

> ครั้งแรกที่รัน ระบบจะสร้างไฟล์ `portfolio.db` ในโฟลเดอร์เดียวกับ `app.py` ให้อัตโนมัติ

## วิธีใช้งาน

### 1. สมัครสมาชิก / เข้าสู่ระบบ
- เปิดหน้าแรก กด **สมัครสมาชิก** กรอกชื่อผู้ใช้ ชื่อที่แสดง และรหัสผ่าน
- ระบบจะพาเข้าสู่แดชบอร์ดโดยอัตโนมัติหลังสมัครสำเร็จ
- ครั้งต่อไปเข้าผ่านเมนู **เข้าสู่ระบบ**

### 2. เพิ่มผลงาน
ไปที่ **ผลงานของฉัน → + เพิ่มผลงาน** แล้วกรอก:

| ช่อง | คำอธิบาย |
|---|---|
| ชื่อผลงาน *          | ชื่อโปรเจกต์/กิจกรรม |
| หมวดหมู่ *           | โปรเจกต์ / งานอบรม-สัมมนา / รางวัล-เกียรติบัตร / อาสาสมัคร / การเรียนรู้ / อื่น ๆ |
| สถานะ *             | กำลังทำ / เสร็จสิ้น / พัก-รอ |
| วันที่ *             | วันที่ทำกิจกรรม |
| จำนวนชั่วโมง         | ชั่วโมงที่ใช้ (นำไปรวมเป็นชั่วโมงสะสม) |
| รายละเอียด          | คำอธิบายเพิ่มเติม |
| ทักษะที่ใช้          | คั่นแต่ละทักษะด้วยเครื่องหมายจุลภาค เช่น `Python, Flask, SQL` |
| ลิงก์อ้างอิง         | URL ผลงาน เช่น GitHub, เว็บไซต์, เกียรติบัตร |

`*` = จำเป็นต้องกรอก

### 3. แก้ไข / ลบผลงาน
ในหน้า **ผลงานของฉัน** แต่ละรายการมีปุ่ม **แก้ไข** และ **ลบ** (การลบมีข้อความยืนยัน)

### 4. ค้นหาและกรอง
หน้า **ผลงานของฉัน** มีแถบค้นหา (ค้นจากชื่อ / รายละเอียด / ทักษะ)
และตัวกรองตามหมวดหมู่และสถานะ

### 5. แดชบอร์ด
สรุป: จำนวนผลงานทั้งหมด, เสร็จสิ้น, กำลังทำ, ชั่วโมงสะสม,
กราฟแท่งแยกตามหมวดหมู่ และรายการผลงานล่าสุด 5 รายการ

### 6. โปรไฟล์
แก้ชื่อที่แสดง, ข้อความแนะนำตัว (Bio) และเปลี่ยนรหัสผ่าน

### 7. พอร์ตโฟลิโอสาธารณะ
เข้าถึงได้ที่ **`/u/<ชื่อผู้ใช้>`** เช่น `http://127.0.0.1:5000/u/somchai`
หน้านี้เปิดดูได้โดยไม่ต้องเข้าสู่ระบบ เหมาะสำหรับส่งลิงก์ให้ผู้อื่น
(ลิงก์ของคุณแสดงอยู่ในหน้าโปรไฟล์)

## เส้นทาง (Routes)

| Path | คำอธิบาย | ต้องล็อกอิน |
|---|---|:---:|
| `/`                       | หน้าแรก | – |
| `/register`, `/login`, `/logout` | จัดการบัญชี | – |
| `/dashboard`              | แดชบอร์ดสรุป | ✓ |
| `/activities`             | รายการผลงาน + ค้นหา/กรอง | ✓ |
| `/activities/new`         | เพิ่มผลงาน | ✓ |
| `/activities/<id>/edit`   | แก้ไขผลงาน | ✓ |
| `/activities/<id>/delete` | ลบผลงาน (POST) | ✓ |
| `/profile`                | แก้ไขโปรไฟล์ | ✓ |
| `/u/<username>`           | พอร์ตโฟลิโอสาธารณะ | – |

## การตั้งค่าสำหรับใช้งานจริง

- กำหนด `SECRET_KEY` ผ่าน environment variable ก่อนรัน:

  ```bash
  # PowerShell
  $env:SECRET_KEY = "ใส่คีย์สุ่มยาว ๆ ที่นี่"
  python app.py
  ```

- ปิด debug mode: แก้บรรทัดท้ายไฟล์เป็น `app.run()` หรือรันผ่าน WSGI server (เช่น `waitress`, `gunicorn`)
- สำรองข้อมูลด้วยการคัดลอกไฟล์ `portfolio.db`

---

## โครงสร้างข้อมูล

**users** — `id, username, password_hash, display_name, bio, created_at`
**activities** — `id, user_id, title, category, status, description, skills, link, activity_date, hours, created_at, updated_at`

รหัสผ่านถูกเข้ารหัสด้วย `werkzeug.security` (ไม่เก็บเป็น plain text)

---

## รีเซ็ตข้อมูลทั้งหมด

ปิดแอป แล้วลบไฟล์ฐานข้อมูล จากนั้นรันใหม่:

```bash
rm portfolio.db
```
